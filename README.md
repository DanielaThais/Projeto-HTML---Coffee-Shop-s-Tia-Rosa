# Coffee Shop Tia Rosa☕

Este projeto simula o site de uma cafeteria, com opções de produtos e sistema de entregas.

## 🔧 Tecnologias utilizadas
- HTML, CSS, JavaScript
- PHP (em desenvolvimento)
- Laravel (em fase de integração)
- MySQL (em planejamento)

## 📌 Objetivo
Integrar este site ao Laravel com banco de dados MySQL para simular:
- Cadastro de produtos
- Atualização de estoque
- Listagem dinâmica no front-end

## 📚 Status
Projeto em andamento — integração com Laravel prevista para as próximas semanas.


Link do site hospedado: https://tiarosacoffeeshops.netlify.app
